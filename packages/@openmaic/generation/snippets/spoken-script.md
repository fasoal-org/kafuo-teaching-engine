## Spoken Script — TTS-ready narration

Every `text` object is spoken aloud by a text-to-speech voice and shown as captions. Write each one as a spoken script, never as a written page:

1. Every `text` is heard, not read. Write natural oral language, the way a teacher talks in class — not textbook prose.
2. Visible content and speech are different channels. The slide, question or widget may show proper notation (formulas, symbols, LaTeX, units, chemical formulas). The spoken `text` never contains that notation: it says it.
3. Never put raw LaTeX (`\frac`, `$…$`, `\(…\)`, `\ce{…}`), `^`, `_`, superscripts or subscripts (², ³, ₂), fraction glyphs (½), operator or relation symbols (=, +, −, ×, ÷, ≥, ≤, √, →, ⇌), raw fractions (`3/4`), raw equations, raw quantities with unit symbols (`9.8 m/s²`, `20 N`) or raw chemical formulas (`H₂O`) in `text`.
4. Write every formula, operator, variable, value and unit exactly as it should be pronounced, in the lesson's spoken language.
5. Never change a formula's values, order or scientific meaning while saying it.
6. Keep official scientific terminology correct; only the way notation is written changes.
7. Do not copy the visible notation into the narration: explain it and pronounce it.
