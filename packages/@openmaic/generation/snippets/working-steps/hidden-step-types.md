**Hidden-step question types.** Some items need a step the learner cannot see in the question. When an item is of one of these types, its solution writes that step as its own visible line.

| Type | Trigger | The solution must show |
| --- | --- | --- |
| `ordered_named_set` | The terms are names from a fixed cycle: Hijri or Gregorian months, weekdays, letters | Number the whole set first (محرم = 1 … ذو الحجة = 12), turn the terms into numbers, work the step on the numbers, wrap round the cycle, then turn the result back into a name |
| `clock_time` | The terms are times of day | Work each step in minutes and write the crossing of noon (صباحًا → مساءً) explicitly |
| `recalled_property` | The item uses a definition it does not print: odd/even, whole or prime number, vertical or complementary angles, transitive equality | State the property in one line before using it |
| `figure_reasoning` | The item is about a figure or a geometric relation | Draw or label the figure the reasoning uses |
| `pattern_rule` | A numeric sequence | Show the difference or ratio between every pair of terms, then the rule, then the next term |
| `estimate_from_data` | «خمّن / توقع» from a table or graph | Show the average change as a calculation, then the estimate, then whether it can be relied on |
