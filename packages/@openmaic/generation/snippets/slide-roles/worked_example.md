**Purpose of this slide.** Solve ONE specific problem completely, showing the reasoning.

**It must contain:**
- the complete problem or context
- the complete solution, step by step
- for each meaningful step: what is being done, why it is being done, and how it relates to the governing concept or rule
- the final result, clearly marked
- a concise takeaway about the reasoning pattern

**What leads, what supports.** The problem leads; the ordered steps form the body; the result and takeaway close it. Use a stepwise structure so each step's what/why is scannable.

**Learner engagement.** The learner should be able to follow every step without the narration.

**Must NOT appear:**
- an abbreviated or incomplete solution
- steps with no reasoning
- a general method detached from this problem (that is a procedure)

**If it does not fit.** Never abbreviate the solution. Present the steps this slide owns completely; the solution continues on a following worked-example slide.

Arrangement is yours to design: choose the hierarchy, grouping and visual structure that serve this purpose best — no fixed arrangement is expected.
