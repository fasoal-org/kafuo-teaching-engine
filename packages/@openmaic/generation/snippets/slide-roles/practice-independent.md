**Purpose of this slide.** Let the learner attempt a task on their own, before any solving support is shown.

**It must contain:**
- the practice task, stated completely and unambiguously
- everything the learner needs to START (given data, the question, the expected form of the response)

**What leads, what supports.** The task is the whole slide. Give it room.

**Learner engagement.** The learner attempts first. Support exists separately and is offered only when the learner asks for it — it is not part of this slide.

**Must NOT appear:**
- ANY solving guidance: no hints, no method, no partial solution, no worked steps, no answer
- phrases that reveal the approach (for example 'use the formula…', 'start by…', 'remember that…')
- a note telling the learner that hints or an explanation exist — the application provides that control

**If it does not fit.** If this cannot fit readably on one slide, present the part this slide owns completely and coherently — never overcrowd, shrink text, or abbreviate the substance; the lesson continues it on a following slide with the same purpose.

Arrangement is yours to design: choose the hierarchy, grouping and visual structure that serve this purpose best — no fixed arrangement is expected.
