**Purpose of this slide.** Teach how two (or a few) related ideas differ and what they share, so the learner can tell them apart and choose between them.

**It must contain:**
- the ideas being compared, each named clearly
- the criteria the comparison uses, stated explicitly
- for each criterion, what each idea says or does — the similarities and the differences
- a key takeaway: how to tell them apart, or when each one applies

**What leads, what supports.** The side-by-side comparison along shared criteria leads; the takeaway supports it.

**Learner engagement.** Make the learner see the difference that matters, not only list two sets of facts.

**Must NOT appear:**
- two separate descriptions with no shared criteria
- a comparison with an idea this lesson does not teach
- a full worked problem (that is a different slide)

**If it does not fit.** If this cannot fit readably on one slide, present the part this slide owns completely and coherently — never overcrowd, shrink text, or abbreviate the substance; the lesson continues it on a following slide with the same purpose.

Arrangement is yours to design: choose the hierarchy, grouping and visual structure that serve this purpose best — a table or parallel columns often help, but no fixed arrangement is expected.
