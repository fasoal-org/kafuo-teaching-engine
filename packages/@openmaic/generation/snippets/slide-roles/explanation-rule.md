**Purpose of this slide.** Teach a rule (law, principle, formula, convention) so it can be applied correctly.

**It must contain:**
- the rule, stated clearly and exactly
- what the rule means and the context in which it holds
- the conditions under which it applies, and exceptions, when they matter
- optionally a visual or a micro-example that demonstrates one application

**What leads, what supports.** The rule statement leads; meaning, conditions and exceptions support it.

**Learner engagement.** Make it clear WHEN the rule applies, not only what it says.

**Must NOT appear:**
- a rule stated with no meaning or context
- a full worked problem (that is a different slide)

**If it does not fit.** If this cannot fit readably on one slide, present the part this slide owns completely and coherently — never overcrowd, shrink text, or abbreviate the substance; the lesson continues it on a following slide with the same purpose.

Arrangement is yours to design: choose the hierarchy, grouping and visual structure that serve this purpose best — no fixed arrangement is expected.
