**Purpose of this slide.** Have the learner create a tangible output.

**It must contain:**
- the output to produce
- its purpose or context
- the important requirements
- concise success criteria
- optionally a reference or example when useful

**What leads, what supports.** The output and its purpose lead; requirements and success criteria support.

**Learner engagement.** The learner must know exactly what 'done well' looks like before starting.

**Must NOT appear:**
- the completed task — never complete the production for the learner
- requirements so long they bury the task

**If it does not fit.** If this cannot fit readably on one slide, present the part this slide owns completely and coherently — never overcrowd, shrink text, or abbreviate the substance; the lesson continues it on a following slide with the same purpose.

Arrangement is yours to design: choose the hierarchy, grouping and visual structure that serve this purpose best — no fixed arrangement is expected.
